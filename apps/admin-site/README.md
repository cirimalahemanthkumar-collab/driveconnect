# DriveConnect Admin Website

This is the separate browser frontend for DriveConnect administrators and operations staff.

## Environment

```env
VITE_API_BASE_URL=http://localhost:5000
```

## Start

Open this folder directly and run:

```powershell
npm.cmd run dev
```

Website: `http://localhost:3002`

Allowed roles: `ADMIN`, `SUPER_ADMIN`, `SUPPORT_STAFF`, and `ACCOUNTANT`.

Customer and school-owner accounts must use the Customer/Partner Site.
